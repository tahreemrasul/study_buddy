Who decides the order?

The steps always run in the same order. Does a model need to decide that every time?

LLM orchestrator (what the app does)
LLM: what next?→overview→LLM: what next?→queries→…
  • Can handle follow-up requests
  • Spends model calls deciding and presenting
  • Can skip a step or stop to ask the user
SequentialAgent
overview→queries→search→outline→guide→Q&A
  • Same order every time
  • No extra model calls for orchestration
  • Each step reads its inputs from state, like {outline}

Use a model where the decision depends on the content, like picking a search tool. Use fixed code where it doesn't.
