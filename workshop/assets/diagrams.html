How a function becomes a tool

ADK reads the function's name, type hints and docstring and describes it to Gemini. Gemini decides when to call it.

Design checkpoint: who decides the order?

Our steps always run in the same order. Do we need a model to decide that each time?

LLM orchestrator (what the app does)
LLM: what next?→overview→LLM: what next?→queries→…
  • Flexible: can handle follow-up requests
  • Extra model call before and after every step
  • Can skip steps or stop to ask the user
SequentialAgent
overview→queries→search→outline→guide→Q&A
  • Fixed order, guaranteed every time
  • No "deciding" calls: fewer model calls and tokens
  • Steps read inputs from state: {outline}

Rule of thumb: use an LLM where a decision really depends on the content (which tool to search with), and plain code where it doesn't.
